# wintermute portfolio

Static personal site for GitHub Pages. Serve locally with `python3 -m http.server 8000`, then open http://localhost:8000. No build or runtime package dependencies.

Palette uses a Tianjin University-inspired deep blue, white and cool gray; it is not a claim of an official brand color specification. University mark sourced from https://www.tju.edu.cn/images/tjulogo.png; blue derivative preserves its geometry and transparency. Motion is an illustrative SVG, not an experimental result. Supports reduced motion and a manual pause button.

Deploy `main` from the repository root using GitHub Pages. Fonts from Google Fonts are optional; system fonts remain available offline.
